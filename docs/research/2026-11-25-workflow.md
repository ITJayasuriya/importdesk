## First slice and boundaries

Import screen: local-only explanation, file/sample selection, explicit delimiter and first-row-header confirmation. Loading has a cancel action and progress; failures keep a readable error and permit retry. Desktop has a source table with 50-row pages; mobile scrolls the table within its own region. Native labeled controls and visible keyboard focus precede custom primitives.

Worker owns the original rows. React receives summaries/pages only. Fatal decoding/parsing/limit errors expose no partial successful dataset. New import jobs replace old workers; session/request/revision identity rejects obsolete replies. No IndexedDB until opt-in persistence is implemented.

This slice establishes import and source preview; mapping, repair and export follow. Do not represent it as an end-to-end alpha.
